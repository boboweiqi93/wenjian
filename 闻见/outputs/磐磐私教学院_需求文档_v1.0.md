# 磐磐私教学院 需求文档 v1.0

## 产品定位

磐磐私人的课程交付平台，面向已付费客户，不对外公开。客户购买课程后获得账号，可在平台内阅读课程、充值积分、查看学习进度。

---

## 技术架构

| 项目 | 方案 |
|------|------|
| **前端** | 极简风格 Web 页面，响应式设计，适配手机和电脑 |
| **后端** | Python Flask |
| **数据库** | SQLite（可平滑迁移到 MySQL/PostgreSQL） |
| **部署** | 云端服务器（Ubuntu/Nginx/Gunicorn） |
| **课程格式** | Markdown |

---

## 积分体系

| 项目 | 规则 |
|------|------|
| 积分汇率 | 1元 = 1积分 |
| 充值方式 | 预留支付接口（微信/支付宝），未来接入 |
| 课程定价 | 每门课单独设置所需积分 |

---

## 用户端功能

### 账户体系
- 用户名 + 密码登录
- 磐磐手动创建账号，设置初始积分

### 首页
- 显示用户名、当前积分余额
- 「我的课程」列表（已购课程，显示阅读进度）
- 「推荐课程」列表（未购课程，显示所需积分）

### 课程库
- 全部课程展示
- 每门课显示：封面、标题、简介、所需积分
- 状态标识：「已解锁 / 可阅读」「待解锁」

### 课程详情
- **已解锁** → 直接展示 Markdown 渲染后的课程内容
- **待解锁** → 显示所需积分 + 「立即购买」按钮

### 购买流程
- 点击「购买」→ 确认弹窗 → 扣除积分 → 课程解锁
- 积分不足时提示充值

### 充值页面
- 显示充值选项（如：¥50 / ¥100 / ¥200）
- 预留微信/支付宝支付接口
- 充值后积分实时到账

### 个人中心
- 积分余额
- 购买记录（时间、课程名称、消耗积分）
- 充值记录

---

## 管理端功能

### 登录验证
- 单独管理员账号（与用户端分开）
- 磐磐专用

### 用户管理
- 创建用户（用户名、初始积分、密码）
- 编辑用户（增减积分、重置密码）
- 查看用户列表及基本信息

### 课程管理
- 创建课程（标题、简介、封面、Markdown 内容、积分价格）
- 编辑课程内容
- 上下架课程
- 设置课程排序

### 权限管理
- 单独给用户解锁某门课程（绕过积分购买）
- 批量操作

### 订单管理
- 所有购买记录（用户、课程、时间、积分）
- 所有充值记录

## 页面结构

```
用户端：
├── /login          登录页
├── /               首页（积分余额 + 我的课程 + 推荐课程）
├── /courses        课程库（全部课程）
├── /course/:id     课程详情（内容阅读）
├── /recharge       充值页面
└── /profile        个人中心

管理端：
├── /admin              管理首页
├── /admin/users        用户管理
├── /admin/courses      课程管理
├── /admin/permissions  权限管理
└── /admin/orders       订单记录
```

## 数据库结构

### users 表
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PRIMARY KEY | 主键 |
| username | VARCHAR(50) UNIQUE | 用户名 |
| password_hash | VARCHAR(255) | 密码加密存储 |
| points | INTEGER DEFAULT 0 | 积分余额 |
| is_admin | BOOLEAN DEFAULT FALSE | 是否管理员 |
| created_at | TIMESTAMP | 创建时间 |

### courses 表
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PRIMARY KEY | 主键 |
| title | VARCHAR(200) | 课程标题 |
| description | TEXT | 课程简介 |
| cover | VARCHAR(500) | 封面图URL |
| content | TEXT | Markdown 内容 |
| points_price | INTEGER | 所需积分 |
| is_published | BOOLEAN DEFAULT TRUE | 是否发布 |
| sort_order | INTEGER DEFAULT 0 | 排序权重 |
| created_at | TIMESTAMP | 创建时间 |

### purchases 表
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PRIMARY KEY | 主键 |
| user_id | INTEGER FOREIGN KEY | 用户ID |
| course_id | INTEGER FOREIGN KEY | 课程ID |
| points_spent | INTEGER | 消耗积分 |
| created_at | TIMESTAMP | 购买时间 |

### recharges 表
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PRIMARY KEY | 主键 |
| user_id | INTEGER FOREIGN KEY | 用户ID |
| amount | DECIMAL(10,2) | 充值金额（元） |
| points | INTEGER | 获得积分 |
| payment_status | VARCHAR(20) | 支付状态（pending/paid/failed） |
| created_at | TIMESTAMP | 充值时间 |

## 补充说明

1. **安全性**：用户密码需使用 bcrypt 等算法加密存储
2. **会话管理**：使用 Flask-Login 或 JWT 实现登录态保持
3. **Markdown 渲染**：使用 markdown 库 + 代码高亮（如 Pygments）
4. **文件上传**：课程封面图支持本地上传或外链
5. **数据备份**：建议每日自动备份 SQLite 数据库文件到云存储
